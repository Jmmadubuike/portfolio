# Joseph Mmadubuike — Technology Builder

Official portfolio for Joseph Mmadubuike: Nigerian technology builder, systems architect, and builder of African digital infrastructure. It also houses the public introduction and roadmap for Kwechiri, an Igbo-inspired programming language in active development.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS

## Local Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

The site is intended for deployment as a Next.js application on Vercel, with the official domain:

```text
https://www.josephmmadubuike.com
```

## Indexing

- Sitemap: `app/sitemap.ts`
- Robots: `app/robots.ts`

## Environment Variables

No required environment variables are currently used.
